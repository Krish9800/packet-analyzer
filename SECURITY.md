# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `packet-analyzer`, please do NOT open a public issue.
Instead, report it responsibly:

1. Email your findings to `security@portfolio.local`.
2. Include reproduction steps, sample PCAP, or proof of concept.
3. Allow up to 48 hours for an acknowledgment and coordinated disclosure schedule.
